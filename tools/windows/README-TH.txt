EarthMart POS — ชุดติดตั้งสำหรับคอมเครื่องอื่น (Windows + Google Chrome)
=====================================================================

วิธีติดตั้ง
1. แตกไฟล์ ZIP นี้ (คลิกขวา > แตกไฟล์ทั้งหมด / Extract All)
2. ดับเบิลคลิก Install-EarthMart.bat แล้วตอบคำถาม
   - จอ: 1 = หน้าขายอย่างเดียว · 2 = มีจอลูกค้าอยู่ทางขวาของจอหลัก
   - เปิดหน้าร้านเองตอนเปิดเครื่องไหม (Y/N)
   - วาง "ลิงก์ตั้งค่าเครื่อง" (ไม่บังคับ — กด Enter ข้ามได้ แล้วไปวางที่หน้าจอแรกทีหลัง)
     เอาลิงก์จากเครื่องที่ใช้งานได้อยู่แล้ว: ตั้งค่า > "คัดลอกลิงก์ตั้งค่าเครื่องอื่น"
3. ได้ไอคอนบน Desktop:
   - EarthMart Counter      = หน้าร้าน (เต็มจอแบบ kiosk, ใบเสร็จพิมพ์ทันทีไม่ถาม)
   - EarthMart Back Office  = หลังร้าน (หน้าต่างปกติ ใช้พิมพ์ป้าย A4 / ดูรายงาน)
4. เปิดหน้าร้านครั้งแรก: (วางลิงก์ถ้ายังไม่ได้วาง) > ล็อกอินด้วย PIN > ตั้งค่า > "ลงทะเบียนเป็นเครื่องหน้าร้าน"
   และให้พนักงานแต่ละคนล็อกอิน 1 ครั้งตอนมีเน็ต (ไว้ใช้ PIN ตอนเน็ตหลุด)

ใช้งาน
- สลับไปโปรแกรมอื่น: Alt+Tab หรือปุ่ม Windows · ออกจากหน้าร้าน: Alt+F4
- หน้าร้านใช้ Chrome แยกของตัวเอง เปิด Chrome ปกติพร้อมกันได้
- พิมพ์ใบเสร็จ: ตั้งเครื่องพิมพ์ใบเสร็จเป็นเครื่องพิมพ์หลัก (Default) ของ Windows
- พิมพ์ป้าย A4: ใช้ EarthMart Back Office (เลือกเครื่องพิมพ์ได้)

อัปเดต / เปลี่ยนจำนวนจอ / เปิด-ปิดการเปิดเองตอนเปิดเครื่อง
- ดาวน์โหลดชุดติดตั้งใหม่ แล้วรัน Install-EarthMart.bat อีกครั้ง (ข้อมูลและการตั้งค่าเดิมไม่หาย)

ติดตั้งไว้ที่: C:\Users\<ชื่อผู้ใช้>\AppData\Local\EarthMart
ถ้าเปิดแล้วไม่ขึ้น: ดู log ที่ %TEMP%\earthmart-launch.log
